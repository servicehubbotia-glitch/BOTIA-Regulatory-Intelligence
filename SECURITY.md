# Reporting a security issue

For a suspected disclosure or a vulnerability, use the contact link in Paloma García Muley’s [professional portfolio](https://servicehubbotia-glitch.github.io/technology-AIportfolio/). Share the affected file, version and a minimal synthetic reproduction. Keep credentials, personal information and private source material out of public issues.

The demonstration uses local JSON inputs. Its workflow checks out this repository with read-only contents permission and runs the tests and replay. The workflow has no scheduled trigger.
